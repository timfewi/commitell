# Security

Security fixes are provided for the latest released version. Older releases
may be asked to upgrade before a report is investigated.

Please do not report vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting from the repository's
**Security** tab and include reproduction steps, impact, and any suggested fix.
Remove API keys, repository contents, and other secrets that are not essential
to the report. You should receive an acknowledgement within seven days.
